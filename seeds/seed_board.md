Starting knowledge for the AI events research agents. These are sources to try; their quality is unknown until an agent has used them.

Source ai-deadlines (slug ai-deadlines) is a directory of AI and machine learning conference deadlines maintained by Hugging Face, label "AI Deadlines", locator https://huggingface.co/spaces/huggingface/ai-deadlines. Its data is also readable as YAML files, one per conference, under https://raw.githubusercontent.com/huggingface/ai-deadlines/main/src/data/conferences/ (for example aaai.yml, neurips.yml, icml.yml, iclr.yml).

Source ccf-deadlines (slug ccf-deadlines) is a directory of computer science conference deadlines with an AI category, label "CCF Deadlines", locator https://ccfddl.com/. Its data is readable as YAML files under https://raw.githubusercontent.com/ccfddl/ccf-deadlines/main/conference/AI/ (for example aaai.yml, nips.yml, cvpr.yml).

Source wikicfp-ai (slug wikicfp-ai) is a feed of calls for papers in artificial intelligence, label "WikiCFP artificial intelligence", locator http://www.wikicfp.com/cfp/rss?cat=artificial%20intelligence. Each item links to an event page with dates, location and deadlines.

Source wikicfp-ml (slug wikicfp-ml) is a feed of calls for papers in machine learning, label "WikiCFP machine learning", locator http://www.wikicfp.com/cfp/rss?cat=machine%20learning.

Source meetup-search (slug meetup-search) is a search pattern for AI meetups on meetup.com, label "Meetup search", locator "site:meetup.com artificial intelligence meetup <city> <month year>". Event pages on meetup.com carry structured event data.

Source luma-search (slug luma-search) is a search pattern for AI events hosted on lu.ma, label "Luma search", locator "site:lu.ma AI <city or topic>". Event pages on lu.ma carry structured event data.

Source conference-search (slug conference-search) is a search pattern for upcoming AI conferences and summits, label "Conference search", locator "AI conference <year> call for papers" and "AI summit <year> <region>".

Source neurips (slug neurips) is the website of the NeurIPS conference, label "NeurIPS", locator https://neurips.cc/. Source icml (slug icml) is the website of the ICML conference, label "ICML", locator https://icml.cc/. Source iclr (slug iclr) is the website of the ICLR conference, label "ICLR", locator https://iclr.cc/. Source ai-engineer (slug ai-engineer) is the website of the AI Engineer conferences, label "AI Engineer", locator https://www.ai.engineer/.
